# Visual Selection Prompt

Select and describe an appropriate educational visual based on the subject.

## Subject → Visual Mapping

- **Math**: equations, graphs, worked steps, number lines
- **Physics**: circuit diagrams, force diagrams, formulas, process flows
- **Biology**: labeled cell diagrams, DNA structures, organ systems
- **History**: timelines, maps, event sequences
- **Programming**: code snippets, output examples, execution flows
- **AI/ML**: architecture diagrams, training graphs, pipeline diagrams

## Rules

1. Visuals must be educational, not decorative.
2. Label all important parts.
3. Keep visuals simple and focused on the concept being taught.
